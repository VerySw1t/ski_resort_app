# Бронирование горнолыжного курорта с прокатом

Веб-приложение к базе `ski_resort` (PostgreSQL): просмотр, добавление, изменение и удаление строк по всем 11 таблицам, плюс страница «Запросы» с запросами из раздела 4.4 отчёта.

## Подключение к базе

PostgreSQL 14 или новее.

База `ski_resort`, кодировка UTF-8, локаль ru_RU.UTF-8.

Хост localhost, порт 5432. Строку подключения приложение берёт из переменной окружения `DATABASE_URL`:

```
DATABASE_URL=postgres://postgres:пароль@localhost:5432/ski_resort
```

Если переменная не задана, используется `postgres://postgres:postgres@localhost:5432/ski_resort`.

## Как создать таблицы

Файл `ski_resort.sql` создаёт базу, одиннадцать таблиц, ограничения и триггер вместимости и заполняет учебные строки. Его выполняют, подключившись к базе `postgres`:

```
psql -h localhost -U postgres -d postgres -f ski_resort.sql
```

Повторный запуск стирает базу `ski_resort` и собирает её заново.

## Как запустить приложение

```
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export DATABASE_URL=postgres://postgres:пароль@localhost:5432/ski_resort   # Windows: set DATABASE_URL=...
flask --app app run
```

Приложение открывается по адресу http://127.0.0.1:5000

## Устройство

| Файл | Что делает |
|---|---|
| `app.py` | маршруты, проверка форм, перевод ошибок PostgreSQL в понятные сообщения |
| `schema.py` | описание таблиц: поля, списки выбора, запросы для списков и страницы «Запросы» |
| `db.py` | соединение с PostgreSQL (`psycopg2`) |
| `templates/`, `static/` | страницы и стили |
| `ski_resort.sql` | скрипт создания базы |

Одни и те же четыре экрана (список, добавление, изменение, удаление) обслуживают все таблицы: новая таблица добавляется описанием в `schema.py`.

## Какие правила и где проверяются

- В форме: обязательные поля, длина текста, границы чисел, порядок дат (выезд позже заезда, конец проката не раньше начала), значения из списков.
- В базе: уникальность телефона и почты, пересечение броней одного номера (`no_room_overlap`), вместимость номера (триггер), запрет удаления строк со ссылками (`ON DELETE RESTRICT`). Приложение показывает эти ошибки обычным сообщением.
- В списке брони при добавлении гостя бронь, где мест уже нет, недоступна для выбора.
